# Wishlist для ШІ-асистентів

Wishlist — це приватний список бажань у Telegram. Цей плагін дає ШІ-асистентові (Claude, Codex або ChatGPT) змогу читати й
змінювати **твої власні** бажання та добірки, коли ти про це просиш.

## Що можна попросити

- «Покажи мої бажання.»
- «Додай кавомолку з цим посиланням.»
- «Поклади кавомолку в мою добірку „День народження“.»
- «Які з моїх бажань ще не лежать у жодній добірці?»
- «Заархівуй бажання „Старі навушники“.»

Це рання версія. Тобі потрібні Telegram, [бот Wishlist](https://t.me/wishlist4ubot) і акаунт у ньому. Підключення поки що
відкрите для обмеженого кола людей: якщо бот не дає підключитися, найпевніше, тобі ще не відкрили доступ — напиши боту.
Плагін — це лише налаштування: ні коду, ні хуків, ні ключів чи паролів. Асистент працює з Wishlist через MCP-сервер за такою
адресою:

```text
https://mcp.wishlist-bot.duckdns.org/mcp
```

## Встановлення

Є два способи. **Плагін** — це підключення разом із навичками: інструкціями, які підказують асистентові, як працювати з твоїми
бажаннями й добірками. **Просто адреса** — лише підключення, без навичок. Першого разу асистент надішле тебе до бота Wishlist —
там ти підтвердиш підключення.

### ChatGPT

1. Відкрий [ChatGPT Plugins](https://chatgpt.com/plugins), натисни плюс і обери **Add custom MCP server**.
2. У полі **Name** впиши `Wishlist`. У розділі **Connection** обери публічну адресу (не **Tunnel**) і встав наведену вище адресу в
   поле **Server URL**.
3. У **Authentication** обери **OAuth** (вхід через підтвердження в боті, без пароля). Не обирай **OAuth or no authentication**,
   бо ChatGPT покаже помилку «The MCP server denied access».
4. Відкрий **Advanced OAuth settings** (розширені налаштування). У **Registration method** обери
   **Client Identifier Metadata Document (CIMD)** — так ChatGPT називає себе серверу. У **Default scopes** (права доступу)
   познач `wishlist:read` (читання) і `wishlist:write` (запис).
5. Познач **I understand and want to continue**, натисни **Create as a plugin**, потім **Connect Wishlist** і підтверди
   підключення в боті Wishlist.

Це лише підключення, без навичок. Ті самі кроки докладніше — у
[docs/chatgpt.md](https://github.com/stingrigs/wishlist-agent-plugin/blob/main/docs/chatgpt.md).

### Claude Code

Плагін (підключення й навички):

```bash
claude plugin marketplace add stingrigs/wishlist-agent-plugin
claude plugin install wishlist@wishlist-plugins
```

Лише підключення за адресою:

```bash
claude mcp add --transport http --scope user wishlist https://mcp.wishlist-bot.duckdns.org/mcp
```

Потім виконай `/mcp` у Claude Code і ввійди в `wishlist`.

### Codex

```bash
codex mcp add wishlist --url https://mcp.wishlist-bot.duckdns.org/mcp
codex mcp login wishlist
```

## Безпека й приватність

- Асистент працює з твоїми власними бажаннями та добірками. У спільній добірці, де ти власник або співавтор (туди свої бажання
  додають й інші люди), він також читає назви й описи чужих бажань. Усе, що він прочитав, потрапляє до ШІ-сервісу, яким ти
  користуєшся.
- Він не може нічого видалити назавжди, прийняти запрошення чи побачити вподобання й тих, хто вподобав.
- Зміни, які побачать інші люди, ти спершу підтверджуєш в асистенті.
- Кожне підключення ти підтверджуєш у боті Wishlist і можеш відключити будь-коли: «⚙️ Налаштування › 🔌 Підключені застосунки» в боті.
- Політику конфіденційності й умови користування ще не опубліковано; посилання з'являться тут.

## Якщо не працює

- Бот пише «🔒 Підключення недоступне»: посилання діє 10 хвилин. Почни підключення знову. Якщо знову те саме, тобі ще не відкрили підключення: напиши боту.
- Код у боті не збігається з кодом на сторінці: не підтверджуй. Натисни «✖️ Не підключати» і почни спочатку.
- ChatGPT пише «The MCP server denied access»: перевір, що в **Authentication** обрано **OAuth**.
- Після підключення асистент не бачить інструментів Wishlist: почни нову розмову.
- Якщо нічого не допомогло, напиши [боту Wishlist](https://t.me/wishlist4ubot).
